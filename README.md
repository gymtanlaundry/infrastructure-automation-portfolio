## Engineering Philosophy

I approach infrastructure and systems engineering with a focus on ownership, automation, security, and long-term maintainability.

My goal is not simply to make systems work. It is to build systems that other engineers can understand, operate, extend, and trust.

I value:

- Automation over repetitive manual processes.
- Infrastructure as Code over undocumented configuration.
- Security integrated into engineering workflows.
- Reusable components over one-off implementations.
- Observability and accountability throughout the deployment lifecycle.
- Documentation and knowledge transfer as part of engineering delivery.
